# Salesforce tutorial recording scripts

These are recording plans, not finished videos. Record actual product screens only after tenant, environment, privacy and execution scope are confirmed. Do not present synthetic material as live evidence.

## Tutorial 1: From org context to a custom scenario

Opening: “A reusable test becomes useful only after it matches your org and your approved business rule.”

Show the synthetic context, its date and visible Lead fields. Explain Stated versus Implemented. Run the local preparation command and show one ready-for-review item alongside unresolved scenarios. Remove the approved rule, rerun into a new directory and show the blocker. Explain why the tool did not run a test. Close with the onboarding worksheet and review checklist.

Capture checklist: title card labeled Synthetic; terminal summary without private paths; scenario bindings; missing-context example; final review checklist. Narration must say “prepared,” not “passed.”

## Tutorial 2: Salesforce integration readiness

Opening: “Authentication can work while the business transaction is still wrong.”

Show the official advisory and source-check date. Explain how to inventory an authentication method with secret values redacted. Show the approved source/target mapping and one actual authorized execution, if available. Compare correlation ID, currency and totals with sensitive values masked. Show a failure or unresolved gap honestly rather than replacing it with a staged green screen.

Capture gate: record only a verified target and permitted synthetic data; no live run is required to publish the explanatory portion. Label any missing execution segment “live demonstration pending.”

## Tutorial 3: A guide that stays connected to evidence

Opening: “A screenshot is helpful, but a customer also needs to know which version and role it represents.”

Select actual reviewed run/case/step results. Demonstrate import into the existing docs-evidence workflow, review text/media, then show the exported guide. Compare a separately reviewed after-change export and explain the refresh decision. Close on the owner and next-review trigger.

Capture gate: run hierarchy, environment and result must match; signed media URLs and credentials stay private. No automatic recapture or semantic-diff claim.

## Recording receipt

For each video retain privately: recording date, presenter, tenant/workspace, environment, rule version, source run IDs, observed outcomes, redaction/media review, reviewer, publication destination and remaining gaps. Public captions disclose synthetic versus live scope. Review the transcript as well as the pixels.
