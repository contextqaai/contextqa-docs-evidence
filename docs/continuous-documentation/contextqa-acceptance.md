## Repeat a case

Use Ship 5 environment 10 and an isolated application workspace. Bind the current staging origin or replace a disposable test origin before replay. Keep an approved guide with a known path, version and original image. Use separate fixtures for tests that change a guide head or edit an asset. The new cases below use the documentation application built from `68ec283` with a seeded guide and real Ship 5 screenshot from result 483.

The native PostgreSQL Database step needs the private hostname and secret binding for this app. Until it is configured, report native REST and database-via-HTTP results independently. For deployment checks, identify the actual serving commit before attributing a screenshot to a customer release.
