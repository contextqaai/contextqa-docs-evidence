## Completeness boundaries

The public index is covered; “all features” behind authenticated UI is not proven. No pricing, account entitlement, model-provider architecture, API beyond published references, or exact performance is inferred. Marketing enablement modules are user-inspired extensions. The attached payments-factory guide is a supplied example, not evidence of this repo's runtime or authorization to run its commands.

Do not replicate unavailable controls: disabled style-document upload, unused default cover/card images, or new standalone Mintlify setup. Do not assume every provider offers all help-center operations. Do not reproduce a separate recorder in conflict with our ContextQA-only evidence requirement.
